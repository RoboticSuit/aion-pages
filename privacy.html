Privacy Policy – Aion

Aion is a personal automation project with a single user: the person who built and runs it. This page exists to satisfy Google's OAuth application requirements.

What it accesses

Aion connects to its one user's own Google Calendar and Google Tasks, using credentials that only that user controls, to read and write their own events and tasks on their own behalf.

What it does with that data

Calendar and task data is used only to run the user's own schedule: creating, reading, changing and removing their own events and tasks, and keeping a private log of what was completed and when. Nothing is sold, shared, published, or used for advertising.

Who else can see it

No one. There is no other user, no analytics service, and no third party with access to this data.

Data retention and deletion

Data lives only in the user's own Google account and in a private database the user controls. Revoking Aion's access at myaccount.google.com/permissions ends all access immediately.

Contact

This project has one user and one maintainer, the same person.
